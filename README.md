# Página de Inicio (Portfolio Base)

Este es un proyecto de práctica de la sección de HTML y CSS Avanzado de **The Odin Project**.

## 🎯 Objetivo del proyecto
Crear una página de inicio (landing page) totalmente responsive a partir de un diseño proporcionado en tres formatos: escritorio, tableta y móvil.

## 🛠️ Tecnologías y Conceptos utilizados
- **HTML Semántico:** Uso de etiquetas como `<header>`, `<main>`, `<section>`, `<footer>` y `<address>`.
- **CSS Grid:** Para la cuadrícula de proyectos, adaptándose de 3 columnas (escritorio) a 2 (tablet) y 1 (móvil).
- **Flexbox:** Para alinear la cabecera, el footer y los iconos.
- **Clip-path:** Para crear el efecto de "ola" diagonal en el fondo azul de la cabecera.
- **Posicionamiento CSS:** Uso de `position: absolute` para hacer que la foto de perfil "flote" y sobresalga de la tarjeta blanca.
- **Media Queries (Responsive):** Para adaptar el diseño a pantallas de móvil (320px) y tableta (600px-900px).
- **Google Fonts:** Uso de las tipografías *Playfair Display* (títulos) y *Roboto* (texto).
- **FontAwesome:** Para los iconos de redes sociales y de las tarjetas de proyectos.

## 🚀 Cómo verlo
Puedes abrir el archivo `index.html` en tu navegador. Para una mejor experiencia con recarga automática, se recomienda usar la extensión **Live Server** de VS Code.
